# Launcher3 ASCII 架构图

```
+-----------------------------------------------------------------------------------+
|                                 Launcher3 架构                                    |
+-----------------------------------------------------------------------------------+

+------------------+        +------------------+        +----------------------+
|   系统事件       |        |   用户交互       |        |  应用组件生命周期    |
| (安装/卸载/更新) |        | (点击/长按/拖放) |        |  (创建/恢复/暂停)    |
+--------+---------+        +--------+---------+        +-----------+----------+
         |                           |                              |
         v                           v                              v
+-----------------------------------------------------------------------------------+
|                                                                                   |
|  +-------------------------+    +-------------------------+    +----------------+ |
|  |      模型层 (Model)     |    |     控制器层(Controller) |    |  视图层(View)  | |
|  |                         |<-->|                         |<-->|                | |
|  | - LauncherModel         |    | - LauncherAppState      |    | - Launcher     | |
|  | - AllAppsList           |    | - DragController        |    | - Workspace    | |
|  | - WidgetsModel          |    | - StateTransition       |    | - CellLayout   | |
|  | - ItemInfo (及子类)     |    |   Animation             |    | - Hotseat      | |
|  | - LauncherProvider      |    | - DeviceProfile         |    | - AllApps      | |
|  | - IconCache             |    |                         |    | - Widgets      | |
|  |                         |    |                         |    |                | |
|  +--+----------+-----------+    +-----+-------------+-----+    +-------+--------+ |
|     |          |                      |             |                  |          |
|     |          |                      |             |                  |          |
+-----+----------+----------------------+-------------+------------------+----------+
      |          |                      |             |                  |
      v          v                      v             v                  v
+------------+ +------------+    +------------+ +------------+    +------------+
| 数据存储   | | 应用/小部件|    | 拖放系统   | | 状态管理   |    | UI组件     |
| 子系统     | | 管理子系统 |    | 子系统     | | 子系统     |    | 子系统     |
+------------+ +------------+    +------------+ +------------+    +------------+

+-----------------------------------------------------------------------------------+
|                                数据流向说明                                        |
|                                                                                   |
| 1. 数据绑定: Model层 -> View层 (加载和显示数据)                                   |
| 2. 用户操作: View层 -> Controller层 -> Model层 (用户操作导致数据更新)            |
| 3. 系统事件: 系统 -> Model层 -> View层 (如应用安装触发更新)                      |
| 4. UI状态转换: Controller层 -> View层 (如切换到"所有应用"视图)                   |
+-----------------------------------------------------------------------------------+
